How it works

Three layers, one seamless experience

RecallCam separates fast visual perception from smart interpretation, keeping real-time performance while building a rich, searchable history.

Detect & track

EfficientDet-Lite0 runs in your browser at up to 30 fps, identifying objects from 80 everyday classes and assigning persistent IDs frame to frame using IoU tracking — no server, no upload.

Interpret interactions

Hand landmarks pinpoint when a person touches an object. A trigger gate compares before-and-after positions to classify events — detected, moved, or returned — with timestamps and thumbnails.

Log & recall

Every event lands in a filterable activity log with a keyframe thumbnail, confidence score, and ISO timestamp. Export the full history as CSV in one click — your inventory, your data.

Features

Built for real inventory work

Runs entirely in the browser

MediaPipe models download once and run locally. No video is streamed to any server, ever. Open the URL on any HTTPS device and start immediately.

Persistent object identity

IoU tracking assigns stable IDs that survive brief occlusions and lighting changes, so "bottle #3" is always the same bottle across its entire session lifespan.

Searchable activity log

Filter by action or object name in real time. Every entry carries a keyframe thumbnail and precise timestamp so you can reconstruct exactly what happened and when.

One-click CSV export

Download the full event log as a CSV with ISO timestamps, object names, actions, and confidence scores — ready for spreadsheets, databases, or audit trails.

Open-vocabulary targeting

Type any COCO class name — bottle, cell phone, laptop, keyboard — and the system narrows instantly to that object. Change it mid-session without restarting.

Real-time performance

The detector runs at up to 30 fps using the GPU delegate. Hand landmarks and IoU tracking add under 5 ms per frame — no queues, no lag, no dropped events.
